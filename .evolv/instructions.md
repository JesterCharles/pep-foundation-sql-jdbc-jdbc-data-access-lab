# JDBC Data Access — Code lab

Move a shop's customers from memory into a database with plain JDBC: a connection URL from the environment, a repository with PreparedStatement and ResultSet mapping, and a transfer that is one transaction.

- **Edit:** the classes in `src/main/java/exercise/` named in the checklist. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 7 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: `README.md` in the project folder.
